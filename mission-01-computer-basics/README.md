# Mission 1 — Know your computer

## 1. Task / objective
Explain Input, Processing, Output and Storage (IPOS), identify hardware and software, and describe three everyday computer-based systems.

## 2. Work completed

### Task 1.1 — IPOS example: searching for a website
| Stage | What happens | Hardware / component |
|---|---|---|
| Input | I type a website address or search words. | Keyboard |
| Processing | The browser and processor handle the request and display the result. | CPU and RAM |
| Output | The webpage appears and may play sound. | Display and speakers |
| Storage | Browser data or downloaded files may be saved. | SSD; optionally cloud storage |

### Task 1.2 — Hardware and software
| Item | Hardware or software? | Software type | Purpose |
|---|---|---|---|
| Keyboard | Hardware | Not applicable | Enters text |
| Mouse / trackpad | Hardware | Not applicable | Controls the pointer |
| Display | Hardware | Not applicable | Shows visual output |
| SSD | Hardware | Not applicable | Stores files |
| macOS | Software | Operating system | Manages computer resources |
| Web browser | Software | Application | Opens websites |
| Text editor | Software | Application | Creates and edits text/code |
| Backup utility | Software | Utility | Helps back up data |
