### Process and PID
A process is a program that is currently running. A PID (process ID) is a number the operating system assigns to identify a running process.

### Absolute and relative paths
- An absolute path describes a location from the filesystem's root.
- A relative path describes a location from the current working directory.

### Permissions
- `r` means read.
- `w` means write.
- `x` means execute (or enter a directory).

### Main responsibilities of an operating system
1. Process management — runs and schedules programs.
2. Memory management — allocates and manages RAM.
3. Device management — coordinates hardware through drivers and system services.
4. File management — organises files and directories.
5. User interface and shell — lets users interact with the computer.
6. Security and permissions — controls access to resources.
